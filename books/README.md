# Books and papers

This directory keeps summaries and legal source links. Modern copyrighted papers should not be copied into the repository merely because a PDF is reachable online.

- [Duke 2014 summary](duke-2014-mock-theta-summary.md) — Ramanujan to the modern theory, with the partition-product route into polynomial Tetris.
- [What is a mock function?](what-is-a-mock.md) — mock theta, mock modular, mock Jacobi, and the limited analogy with software mocks.

## Core technical references

- Sander Zwegers, *Mock Theta Functions* (PhD thesis, Utrecht, 2002)  
  https://research-portal.uu.nl/en/publications/mock-theta-functions/  
  arXiv: https://arxiv.org/abs/0807.4834
- Don Zagier, “Ramanujan's Mock Theta Functions and Their Applications [d'après Zwegers and Ono-Bringmann]”, Astérisque 326 (2009), 143–164  
  https://archive.numdam.org/item/AST_2009__326__143_0/
- Ken Ono, “Mock Theta Functions, Ranks, and Maass Forms” — survey connecting mock theta functions, partition ranks and harmonic weak Maass forms.
- Kathrin Bringmann, Ken Ono and Robert Rhoades, “Eulerian Series as Modular Forms”, JAMS 21 (2008), 1085–1104 — differences of mock theta functions and harmonic Maass forms.
- Kathrin Bringmann and Ken Ono, work on lifts to harmonic weak Maass forms and applications to partitions — useful for the general framework around Ramanujan's examples.
